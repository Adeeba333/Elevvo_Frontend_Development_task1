### Problem Statement

Develop a responsive and accessible sidebar navigation component using HTML5, CSS3, and JavaScript ES6+. 
The sidebar should contain a logo placeholder, 4–5 navigation links with icons, and a toggle button that allows users to open and close the sidebar.
Semantic HTML, WCAG/ARIA practices, Flexbox or CSS Grid, and responsive design should be used to ensure a clean and accessible layout. 
JavaScript DOM manipulation and event handling should control the sidebar’s toggle behavior, while CSS transitions provide a smooth open/close animation.
